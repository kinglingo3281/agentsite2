# Delaware Beach Real Estate Website

A responsive, customer-facing real-estate website for a Delaware coastal agent, covering Rehoboth Beach, Dewey Beach, Lewes, and Sussex County. Built to turn a service business into a clear, search-friendly online presence with strong lead capture.

## What it demonstrates

- content-driven information architecture across buy, sell, search, listings, area guides, and market-intel sections
- responsive, mobile-first UI with `framer-motion` interactions
- lead-capture and contact journeys designed around a real customer decision flow
- SEO foundations: semantic structure, `sitemap.ts`, and `robots.ts`
- markdown-driven content via `gray-matter` for maintainable insights/area pages
- production deployment configuration

## Stack

- Next.js / React / TypeScript
- Tailwind CSS
- Framer Motion
- gray-matter (markdown content)

## Notes

Branding uses placeholder identity ("Agent Name") in this public version; client-specific content, media, and configuration are not included.
